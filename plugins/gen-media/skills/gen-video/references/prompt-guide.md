# Prompt Guide — 视频

把模糊需求升级为 production-grade brief。用户语言回复。模型目录与切换见 `list-models` 命令输出（脚本是唯一真源）。

## 六槽位

| 槽位       | 要什么                         | 示例                                |
| ---------- | ------------------------------ | ----------------------------------- |
| 主体+动作  | 什么在动、怎么动（一镜一主体） | 饮料瓶从冰块中缓缓升起              |
| 环境       | 地点、时间、天气               | 黑色大理石台面，夜景影棚            |
| 镜头       | 一镜一个运动                   | 低角度环绕（orbit）                 |
| 时间线节拍 | 按秒切分                       | 0-2s 升起；2-4s 水珠飞溅；4-5s 定格 |
| 格式       | 比例/分辨率/时长               | 16:9 / 1080P / 5s                   |
| 光线与情绪 | 具名光线 + 单一情绪            | 金色轮廓光，史诗感                  |

缺槽位 → 从请求推断并一行声明假设；推断不了且猜错烧 Credits → 问，最多 2 问。

## 镜头运动词汇

- **推**：缓慢推进（slow push-in）、快速推进（crash zoom）
- **拉**：拉远揭示（pull-back reveal）
- **摇**：水平摇镜（pan）、垂直摇镜（tilt up/down）
- **移**：轨道横移（tracking shot）、环绕（orbit / arc shot）
- **特殊**：无人机俯冲（drone dive）、升格慢动作（slow motion）、希区柯克变焦（dolly zoom）

## 时间线模板

```
0-2秒：[建立镜头/起始状态]；2-4秒：[动作发展]；4-5秒：[落幅/定格]
```

无节拍 = 静止帧。5 秒以内至少 2 个节拍，长镜头最多 3 个。

## 示例

```
夜晚的赛博朋克街道，霓虹灯在雨后地面形成倒影。
0-2秒：镜头低角度掠过积水路面；2-4秒：缓慢抬升，揭示街道尽头的全息广告牌；
4-5秒：定格于广告牌特写。轨道横移加缓慢抬升，体积光穿过雨雾，电影级色调。
```

## 常见失败与对策

| 症状              | 对策                                        |
| ----------------- | ------------------------------------------- |
| 画面静止不动      | prompt 缺动作动词；补"缓慢推进""升起""旋转" |
| 主体变形/融化     | 主体太复杂；一镜一主体                      |
| 出现不想要的人/字 | 显式写"无人物、无文字"                      |
| 节奏混乱          | 用时间线节拍重写                            |

## 引导话术（agent 用）

需求模糊时给 3 个方向，每个一行（场景 + 镜头），让用户选：

`A. 产品旋转展示（环绕镜头） B. 冰块爆裂瞬间（升格慢动作） C. 城市夜景运镜（无人机俯冲）`

选定后再补全槽位，一次最多问 2 个问题。
