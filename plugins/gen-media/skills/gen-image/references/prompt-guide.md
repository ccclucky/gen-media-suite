# Prompt Guide — 图片

把模糊需求升级为 production-grade brief。用户语言回复。模型目录与切换见 `list-models` 命令输出（脚本是唯一真源）。

## 五槽位

| 槽位       | 要什么                   | 示例                           |
| ---------- | ------------------------ | ------------------------------ |
| 主体       | 是什么 + 什么状态        | 能量饮料瓶，瓶身凝结冰霜水珠   |
| 用途与画幅 | 广告/海报/图标 → 定 size | 横版广告 → 2720x1536           |
| 风格       | 摄影/插画/3D/扁平        | 商业广告摄影                   |
| 光线与色彩 | 具名光线 + 具名颜色      | 影棚柔光加金色轮廓光，红金配色 |
| 图内文字   | 逐字保留或确认无文字     | 大字 "燃"                      |

缺槽位 → 从请求推断并一行声明假设；推断不了且猜错浪费生成 → 问，最多 2 问。

## 配方模板

**商业产品图**

```
[产品] 商业广告摄影，[材质/状态]，[构图：居中/三分/微距特写]，
[光线]，[配色]，[背景：纯色渐变/场景虚化/材质台面]，高端质感，8K 细节
```

**海报**

```
[主题] 海报设计，[版式：大字报/极简/拼贴]，[主视觉]，
[字体风格]，[配色]，[情绪]，印刷级品质
```

图内文字用引号标出：`画面中央大字 "燃"，副标题 "BREAK THE LIMIT"`。

**插画 / 概念艺术**

```
[场景] [风格：赛博朋克/水墨/吉卜力/扁平矢量] 插画，[主体与动作]，
[环境细节]，[光线氛围]，[镜头：广角/俯视/特写]
```

**摄影写实**

```
[主体]，[镜头：35mm 街拍/85mm 人像/微距]，[光线]，
[时间/天气]，[色调：胶片感/高对比/低饱和]，景深虚化
```

## 质量词汇库

- **光线**：柔光箱、伦勃朗光、逆光剪影、霓虹反射、体积光（丁达尔）、烛光暖调、冷调月光
- **构图**：对称、引导线、框中框、负空间、鸟瞰、虫眼视角、荷兰角
- **质感**：磨砂、金属拉丝、玻璃折射、水珠凝结、烟雾弥漫、颗粒胶片感
- **风格锚点**：极简主义、包豪斯、国潮、Y2K、蒸汽波、侘寂

## 引导话术（agent 用）

需求模糊时按用途给 3 个方向，每个一行，让用户选：

`A. 影棚产品特写（红金，冰霜质感） B. 场景化生活方式（健身房背景） C. 极简海报（大字报排版）`

选定后再补全槽位，一次最多问 2 个问题。
