# 生图

通过用户自己的 New API 网关生图。脚本：本 skill 目录下的 `scripts/gen_media.py`。

> 语言铁律：面向用户的文字一律中文——brief 卡片表头与内容、提问、拍板门、报错解释。送给模型的 prompt 也用中文。脚本 stdout 英文，读完后翻译再回。

## 首次配置（onboard）

1. 跑 `python "<skill-dir>/scripts/gen_media.py" show-config`。
   - 打出 Base URL + 掩码 Key → 配置完成，跳过本段。
   - stderr 含 `CONFIG_MISSING` → 继续。
2. 直接在对话里收 **Base URL** 和 **API Key**（一句话一起问，或分两行收）。
3. 收齐后跑：

   ```bash
   python "<skill-dir>/scripts/gen_media.py" configure --base-url "<url>" --api-key "<key>"
   ```

   Key 只在本次对话出现这一次；之后只用 `show-config` 的掩码输出。

4. 再跑 `show-config` 验证，看到掩码 Key 即完成。

> 安全说明（一句话带过）：Key 写入本地 `~/.gen-media/config.json`（权限 600），经过本次对话一次；介意者用环境变量 `GEN_MEDIA_BASE_URL` + `GEN_MEDIA_API_KEY`（完全绕过对话）。

## 选模型

配置已有 `image_model` 且用户未要求换模型 → 跳过本段。

需要选/换时：

1. 跑 `list-models`，把目录给用户看。
2. 按意图推荐默认：商业/产品图 → `wan2.7-image-pro`；图内文字多 → `qwen-image-2.0-pro`；省额度草稿 → `wan2.7-image`。
3. 持久化：`set-model --image <model>`。单次试：生成命令加 `--model <model>`。
4. 完成判定：`show-config` 打出所选图片模型。

## 打磨 brief

先补齐这五个槽位；能从请求推断的就填上并在卡片里标「假设：…」，推断不了且猜错会浪费生成时才问（最多问 2 个）：主体、用途与画幅、风格、光线与色彩、图内文字（逐字原文用引号，否则「不加字」）。

- 模糊请求（「来张好看的」「随便」）→ 给 3 个方向（主体+风格+配色，每个一行），让用户挑；选完再补其余槽位。
- size —— 默认 `2048x2048`；16:9 `2720x1536`；9:16 `1536x2720`；4:3 `2304x1728`；3:4 `1728x2304`。
- 张数默认 **1**；只有用户明确要对比/多选时才 >1，并在卡的规格行写明。
- ≥2 槽位靠推断，或用户说「更好/优化/换风格」→ 先读 `references/prompt-guide.md`。
- 完成判定：五槽位填好 + 由五槽位拼出**最终 prompt 逐字文本** + size/张数/模型定好，中文卡片摆出（模板见拍板门）。本步产出=中文卡片，不是文件。

## 拍板门

生成烧额度，先让用户拍板。用下面这张**固定中文卡片**摆出 brief（表头与内容一律中文，假设项写「假设：…」）。「最终 prompt」行=逐字送模型的文本，由五槽位拼成；用户拍的就是这串字：

| 槽位        | 内容                             |
| ----------- | -------------------------------- |
| 主体        | …                                |
| 用途/画幅   | …                                |
| 风格        | …                                |
| 光线/色彩   | …                                |
| 图内文字    | …                                |
| 最终 prompt | <逐字送模型的中文文本>           |
| 规格        | <size> · <张数>张 · 模型 <model> |

卡片下方补一句 affordance：「想换模型/张数/尺寸/任何一格，直接说；说『确认/行/ok』即按此卡逐字生成。」

**拍的是这张卡本身**——最终 prompt 与规格被逐字锁定。生成那一刀必须用卡上的 prompt / size / 张数 / model，一字不改。

**报错或想降级/换任何参数 → 这次不作数**：重摆一张新卡，让用户重新拍板，才能再消耗额度。绝不静默换模型，也绝不偷偷多生成张数。

判定（满足其一才进生成，否则不算拍板）：

- 肯定词（行 / 可以 / 生成 / ok / 确认 / 就这个 / 嗯）→ 进生成。
- 修改指令（换 16:9 / 改插画风 / 加文字「燃」/ 来 2 张对比）→ 改对应格，重摆卡片，再问。
- 模糊或无关回复 → 追问一次，仍不明确就保持等待。
- 例外（迭代）：用户基于上一张的修改指令（「再来一版换红色」「角度改俯拍」）→ 改对应格，**只摆变化格 + 新最终 prompt + 新规格**（delta 卡），等一个肯定词再生成；不必重摆未变的格。

## 生成

```bash
python "<skill-dir>/scripts/gen_media.py" image --prompt "<与拍板卡逐字一致的中文 prompt>" --size "<宽x高>" --count <张数>
```

- `--count` 跟卡上张数走，默认 1。
- 网关若返回多于卡上张数的有效文件，全部保存但如实告知「请求 N 张，网关给了 M 张」。
- 文件本地存在前不许声称成功。

生成后只回报：每个文件绝对路径 + 一句效果观察 + 一个下一版方向。最终 prompt 已在拍板卡确认过，**不再重复贴**（用户问起再给）。

## 迭代

交付后给恰好一个下一版方向（配色/角度/变体），然后停。神图到手 → 建议用 gen-video 让它动起来。

## 规则

- 只用自带脚本。
- Key 仅落 `~/.gen-media/config.json`；回复里 Key 一律掩码。
- 默认存当前工作目录，除非用户指定输出目录。

用户要更新 gen-media → 走宿主的插件/技能更新机制（Claude Code：`/plugin update gen-media`；Codex/WorkBuddy：拉仓库重拷 skill 文件夹）。配置在 `~/.gen-media/config.json`，skill 目录之外，更新不影响。
